ABSTRACT 
The rapid expansion of artificial intelligence tools and automated rephrasing software has 
fundamentally altered academic writing, rendering traditional N-gram and string-matching 
plagiarism detectors largely ineffective against modern techniques like synonym substitution 
and AI-driven paraphrasing. To address these vulnerabilities, this project introduces an AI-
Driven Academic Integrity System featuring a purely software-based architecture designed 
for 100% local, privacy-preserving deployment without reliance on third-party cloud APIs.  
The proposed solution replaces rigid word-for-word matching with a hybrid dual-engine 
analytical framework. The first component utilizes Sentence-BERT (SBERT) dense 384-
dimensional vector embeddings (specifically all-MiniLM-L6-v2) to measure deep semantic 
similarity via Cosine Distance, successfully capturing paraphrased content, active-to-passive 
voice shifts, and structural rephrasing. The second component employs statistical stylometric 
profiling evaluating document Perplexity (token predictability) and Burstiness (variance in 
sentence length and structural rhythm) to detect text generated directly by Large Language 
Models (LLMs).  
Developed using Python (PyPDF2, python-docx, NLTK, PyTorch) for document ingestion 
and natural language processing alongside React.js and Tailwind CSS for the user interface, 
the system presents results through an interactive dashboard featuring dynamic threshold 
sliders and a side-by-side color-coded sentence heatmap. The architecture is containerized via 
Docker to guarantee data sovereignty, intellectual property protection, and cost-effective 
execution. System evaluation includes functional unit testing, User Acceptance Testing 
(UAT) at Universal Technology and Management University (UTAMU), performance latency 
benchmarking, and statistical accuracy validation using Precision, Recall, and F1-Score 
metrics.  
Keywords: Academic Integrity, Sentence-BERT, Stylometrics, Perplexity, Burstiness, 
Paraphrase Detection, AI Text Detection, Vector Embeddings, Cosine Distance, React.js.

1.2) Background to the Problem 
The rapid proliferation of artificial intelligence tools and automated text-rephrasing software 
has fundamentally altered how students compose academic papers, presenting a severe 
challenge to traditional academic integrity frameworks (Najjar et al., 2025) . Historically, 
universities have relied on legacy software utilizing N-gram and string-matching algorithms 
to scan databases for verbatim word overlap. However, modern students can effortlessly 
bypass these systems using tools like ChatGPT and QuillBot to swap synonyms, restructure 
sentences, and alter grammatical voice while retaining the exact original context (Najjar et 
al., 2025). As a result, string -matching detectors yield false -negative 0% similarity scores 
for heavily paraphrased or AI -assisted submissions, failing to identify stolen ideas or 
uncredited machine authorship (Najjar et al., 2025). Furthermore, existing commercial 
detection platforms often operate as proprietary cloud services  that require costly 
subscriptions, demand heavy infrastructure, and present data privacy risks by uploading 
student intellectual property to third-party databases (Najjar et al., 2025). 
To bridge this gap, a clear need exists for a lightweight, purely software -based solution 
capable of evaluating semantic meaning alongside statistical writing patterns without 
relying on external web -crawling infrastructure. Deep contextual models like Sen tence-
BERT (SBERT) project full sentences into high -dimensional vector spaces, allowing

1.3) Problem Statement 
Traditional plagiarism detection tools mainly rely on comparing words and sentence 
structures, making them less effective at identifying AI-assisted paraphrasing and the

meaning, causing traditional plagiarism checkers to report 0% similarity even when 
the content has been copied or rewritten. To address these limitations, this project 
develops a lightweight, locally installed software application that combines Sentence-
BERT embeddings to measure the semantic similarity between sentences with 
Perplexity and Burstiness analysis to help detect text that may have been generated by 
AI.

CHAPTER 2: LITERATURE REVIEW 
2.1) Introduction 
Generative AI and advanced NLP tools have transformed academic writing, rendering 
traditional N-gram and string-matching plagiarism detectors ineffective against synonym 
substitution and automated paraphrasing. To address these vulnerabilities, modern 
frameworks integrate deep semantic vector embeddings (Sentence-BERT) with statistical 
stylometrics (Perplexity and Burstiness) to catch both contextually rephrased content and 
machine-generated text. This literature review synthesizes existing research on legacy 
matching limitations, transformer-based semantic modeling, stylometric AI detection, and 
local privacy-preserving software architectures 
2.2) Theoretical Review 
The design and analytical framework of the proposed dual-engine academic integrity system 
are grounded in three core computational theories: the Vector Space Model & Distributional 
Semantics for paraphrase detection, Information Theory for token predictability modeling, 
and Stylometric Variation Theory for structural AI text profiling. 
2.2.1) Vector Space Model & Distributional Semantics 
i. Theoretical Foundation 
Grounded in John Rupert Firth’s (1957) Distributional Hypothesis  which posits that words or 
linguistic expressions occurring in similar contexts carry similar semantic meanings  the 
Vector Space Model (VSM) projects textual units into continuous, high-dimensional vector 
spaces (Manning et al., 2024). Unlike traditional lexical string-matching algorithms (N-
grams) that treat words as discrete, isolated symbols, distributional models represent entire 
sentences as dense coordinate points in vector space (Devlin et al., 2024). 
ii. Application to Paraphrase Detection 
The semantic vector engine utilizes a pre-trained Sentence-BERT (SBERT) transformer 
model (all-MiniLM-L6-v2) (Reimers & Gurevych, 2024). The model extracts full-sentence 
contextual information by mapping each segmented sentence si into a dense 384-dimensional

2.2.2) Information Theory & Token Predictability (Perplexity) 
i. Theoretical Foundation 
Derived from Claude Shannon’s (1948) Information Theory, entropy measures the 
average uncertainty or information density inherent in a stochastic sequence (Cover & 
Thomas, 2024). In computational linguistics, Perplexity is an exponential transformation 
of cross-entropy, measuring how effectively a language model predicts a given sequence 
of tokens (Jurafsky & Martin, 2024). 
ii. Application to AI Text Detection 
Generative Large Language Models (LLMs) operate by sampling tokens that maximize 
probability distributions over large training corpora (Radford et al., 2024). Consequently, 
machine-generated text exhibits low cross-entropy and highly predictable token 
sequences (Mitchell et al., 2025). Conversely, human writers naturally incorporate 
unexpected vocabulary, domain-specific metaphors, and creative phrasing, producing 
higher statistical uncertainty (Tian et al., 2025).

2.2.3) Stylometric Variation Theory (Burstiness) 
i. Theoretical Foundation 
Stylometry quantifies individual writing style and structural dynamics (Stamatatos 
et al., 2024). Goh and Barabási (2008) introduced the mathematical formulation of 
Burstiness to evaluate temporal clustering and structural variance within complex 
systems. Applied to linguistics, burstiness measures the rhythmic variance in 
sentence length and syntactic complexity across a document (Gehrmann et al., 
2024). 
ii. Application to Structural Profiling 
Human writing naturally displays high structural variation a long, multi-clause 
analytical sentence is frequently followed by a brief, direct summary sentence 
(Kirchenbauer et al., 2024). In contrast, generative AI models select tokens using 
constrained sampling strategies (such as top-p or nucleus sampling), producing 
uniform sentence lengths and repetitive structural rhythms (Gehrmann et al., 
2024).

2.4) How the Gap Was Identified 
The research gap justifying the development of the proposed system was identified through a 
systematic multi-perspective approach combining literature synthesis, comparative empirical 
analysis, and institutional requirement evaluations: 
➢ Analysis of Legacy Detection Limitations: Reviewing existing literature on string-
matching and N-gram algorithms revealed that traditional plagiarism detectors (e.g., 
Turnitin) rely on verbatim lexical overlap. When exposed to modern paraphrasing 
tools (e.g., QuillBot) or LLM-generated text, these systems frequently return false-
negative 0% similarity scores, failing to recognize semantic equivalence across 
rephrased content (Liang et al., 2024; Tuan et al., 2026).

➢ Evaluation of Disjointed Detection Paradigms: Examining standalone AI detectors 
(e.g., GPTZero) demonstrated a clear operational disconnect. While stylometric 
metrics (Perplexity and Burstiness) effectively flag machine-generated text, they 
cannot perform document-to-document cross-referencing to catch semantic 
paraphrase plagiarism (Tian et al., 2025). Conversely, semantic vector engines 
(SBERT) identify contextually rephrased text but cannot independently determine if a 
single document was authored by an LLM (Tuan et al., 2026). Existing solutions treat 
paraphrase detection and AI authorship as isolated problems rather than unified 
analytical workflows. 
➢ Privacy and Infrastructure Audit in Higher Education: Assessment of institutional 
deployment constraints highlighted that commercial detection platforms enforce 
cloud-dependent architectures. This requires uploading student manuscripts to 
external servers, creating data privacy vulnerabilities, intellectual property exposure, 
and recurring subscription costs that are prohibitive for resource-constrained 
universities (Kaufman et al., 2024; Stallings, 2025). 
➢ Synthesis of the Identified Gap: The overarching gap identified is the absence of a 
unified, lightweight, and 100% offline software platform that integrates transformer-
based semantic vector embeddings (all-MiniLM-L6-v2) and statistical stylometric 
profiling into a single interactive visual dashboard. 
2.3.2 How the Gap is Addressed by This Study 
To address the limitations identified in existing literature, this study proposes a unified, 
lightweight, and offline academic integrity platform. The system bridges these technological 
and architectural gaps through four core interventions: 
➢ Dual-Engine Unified Architecture: Instead of treating paraphrase detection and AI 
authorship as isolated tasks, the system integrates Sentence-BERT semantic vector 
embeddings (all-MiniLM-L6-v2) with statistical stylometric profiling (Perplexity and 
Burstiness) into a single analytical pipeline. This ensures simultaneous detection of 
semantic plagiarism and machine-generated text. 
➢ Semantic Vector Matching Over Lexical Overlap: By replacing legacy N-gram 
string matching with dense 384-dimensional vector comparisons via Cosine Similarity

➢ Containerized, Privacy-Preserving Offline Execution: The entire software

CHAPTER 3: METHODOLOGY 
3.1) Introduction 
This chapter presents the methodology used to design, develop, test, and evaluate the 
proposed AI-Driven Academic Integrity System. Following the structured systems 
development  framework adopted in the eWitness Vault methodology, the development 
process follows an Agile software design lifecycle divided into six distinct, iterative phases: 
requirements gathering, system design and architecture, dataset collection and preprocessing, 
system development, system testing and security validation, and final evaluation.  
3.2) Requirement Gathering and Research Design 
The requirement gathering and research design phase focuses on defining functional, 
technical, and domain-specific requirements for paraphrase detection and AI authorship 
profiling. Primary requirements will be gathered through three core activities:  
• Stakeholder Interviews: Structured discussions with faculty members, academic 
integrity reviewers, and university IT administrators at UTAMU to identify 
current workflows, pain points in identifying AI-paraphrased assignments, and UI 
requirements for explainable feedback.  
• Document & Policy Review: Analyzing institutional academic integrity policies 
and standard research submission guidelines to define evaluation metrics and 
baseline similarity thresholds.  
• Observation & Baseline Benchmarking: Evaluating legacy string-matching and 
N-gram plagiarism checking software to document false-negative rates when 
processing paraphrased text and raw LLM output.
